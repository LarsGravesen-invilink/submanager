# SubManager — Менеджер VPN подписок

<div align="center">

**Современная панель управления VPN подписками с кодированием ссылок.**

Создавайте, управляйте и распространяйте подписки для VPN клиентов (Incy, Happ, V2Ray, Clash, Shadowrocket, Hiddify и других).

</div>

---

## ⚡ Установка одной командой

```bash
bash <(curl -sL https://raw.githubusercontent.com/LarsGravesen/submanager/main/install.sh)
```

### Или вручную:

```bash
git clone https://github.com/LarsGravesen/submanager.git
cd submanager
sudo bash install.sh
```

## 🔧 Что делает установщик

1. **Проверяет домен** — DNS A-запись должна указывать на сервер
2. **Устанавливает зависимости** — Node.js 20, PostgreSQL, Nginx
3. **Настраивает базу данных** — Создаёт пользователя и БД
4. **Собирает приложение** — `npm install && npm run build`
5. **Получает SSL** — Автоматически через Certbot
6. **Настраивает автозапуск** — Systemd сервис
7. **Настраивает cron** — Обновление подписок каждые 5 минут

## 📋 Возможности

### Панель управления
- 🔐 **Безопасная авторизация** — Первый вход создаёт администратора
- 🛡️ **Защита от перебора** — Блокировка IP после 5 неудачных попыток
- 🔒 **Шифрование паролей** — bcrypt с 12 раундами

### Подписки
- ✅ Создание подписок с произвольными ключами (vless, vmess, trojan, ss, hysteria2 и др.)
- 🔗 Импорт из внешних источников (3x-UI, raw файлы, другие подписки)
- 📋 Поддержка JSON, Base64, текстовых форматов
- 🔄 Автообновление из источников
- ⏰ Настраиваемое время жизни
- 📊 Статистика обращений (IP, устройство, дата)
- ⏸️ Приостановка без удаления
- ✏️ Полное редактирование

### Клиентская страница
- 🎨 Настраиваемый логотип и заголовок
- ⏱️ Таймер оставшегося времени в реальном времени
- 📱 Кнопка "Добавить в клиент" (Happ, Incy, V2RayNG, Streisand, Hiddify, Shadowrocket)
- 📷 Генерация QR-кода
- 🖥️ Адаптивный дизайн для смартфонов и ПК

### Техническое
- 🔗 Автоматическая маршрутизация — VPN клиенты получают ключи, браузеры видят страницу
- 🆔 Дедупликация ключей по fingerprint
- 🔄 Автоматическое удаление исчезнувших ключей из источника
- 📝 Кастомные имена ключей

## 🛠️ Управление

```bash
# Статус сервиса
systemctl status submanager

# Перезапуск
systemctl restart submanager

# Логи в реальном времени
journalctl -u submanager -f

# Остановка
systemctl stop submanager
```

```
/opt/submanager/
├── src/
│   ├── app/           # Next.js App Router
│   │   ├── api/       # API endpoints
│   │   ├── dashboard/ # Панель управления
│   │   └── s/         # Публичные страницы подписок
│   ├── db/            # Drizzle ORM схема
│   └── lib/           # Утилиты (auth, keys parsing)
├── install.sh         # Установщик
├── .env               # Конфигурация
└── package.json
```

## 🔐 Безопасность

- Пароли хэшируются bcrypt (12 раундов)
- JWT токены для сессий (24 часа)
- Защита от брутфорса (5 попыток / 15 минут)
- HTTPS через Certbot
- Секреты хранятся только на сервере

## 📝 Требования

- Ubuntu 22.04 / 24.04
- 1 GB RAM минимум
- Домен с A-записью на IP сервера
